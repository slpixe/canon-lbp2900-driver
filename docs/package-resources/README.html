Canon LBP2900 community driver — preview

This is unofficial GPLv3 software. The hardened fork has automated tests but has not yet been tested with a physical printer. It is not certified by Canon or Apple.

This installer adds only the CUPS filter and printer definition. It does not add a login app, create a queue, change security settings, or install a background service.

After installation: connect the printer, open System Settings → Printers & Scanners → Add Printer, select the Canon USB printer, then choose Other under Use and select /Library/Printers/PPDs/Contents/Resources/CanonLBP2900-Slpixe.ppd.

For the optional progress app, name the printer queue Canon_LBP2900_Slpixe when adding it, or use the repository's explicit-URI installer to create that queue. The progress app is a separate download.

More information: https://github.com/slpixe/canon-lbp2900-driver
